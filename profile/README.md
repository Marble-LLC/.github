# Marble

**Technology made useful.**

Marble LLC is a technology company building software, digital products, and tools designed to make everyday work simpler.

We create products with a focus on simplicity, reliability, thoughtful design, and a great user experience.

## What we build

Marble works across software and technology, including:

- Web applications
- Desktop applications
- Developer tools
- Productivity software
- Cloud services
- Experimental technologies

Our projects range from small ideas and experiments to complete products used in everyday workflows.

## Our approach

We believe good technology should feel straightforward.

That means reducing unnecessary complexity, designing around people, and building products that do their job well without getting in the way.
